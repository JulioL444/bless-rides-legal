1. Alcance

Esta Política de Privacidad explica cómo Bless Rides recopila, usa, almacena y protege la información de pasajeros y conductores que utilizan la aplicación móvil Bless Rides.

2. Información que recopilamos

Podemos recopilar los siguientes datos, según el tipo de usuario y las funciones utilizadas:

  • Datos de cuenta: nombre, correo electrónico, foto de perfil y datos obtenidos mediante Google Sign-In.
  • Datos de perfil: número de teléfono, rol de usuario, estado de cuenta y preferencias básicas.
  • Ubicación: ubicación GPS precisa, punto de recogida, destino, rutas, distancia estimada y datos necesarios para prestar el servicio de viaje.
  • Datos de viaje: solicitudes, viajes aceptados, cancelados o completados, historial, tarifas, estados del viaje y datos operativos relacionados.
  • Chat y soporte: mensajes enviados dentro de la app, imágenes compartidas durante un viaje o para soporte, reportes e incidencias.
  • Verificación visual del pasajero: fotos o selfies solicitadas para ayudar al conductor a identificar al pasajero y mejorar la seguridad del viaje.
  • Datos de conductor: licencia, documentos de identidad, foto del conductor, selfie, datos del vehículo, placa, marca, modelo, color, documentos del vehículo, seguro/SOAT u otros documentos requeridos para revisión.
  • Wallet y pagos: recargas, saldo, comisiones, comprobantes, referencias de transacciones, datos relacionados con Yappy u otros métodos de pago disponibles.
  • Notificaciones: token de notificación push, estado de notificaciones y mensajes operativos enviados al usuario.
  • Datos técnicos: identificadores del dispositivo, sistema operativo, errores, registros técnicos, rendimiento, dirección IP aproximada y datos necesarios para seguridad y diagnóstico.

3. Cómo usamos la información

Usamos la información para:

  • Crear y administrar cuentas de usuario.
  • Permitir el inicio de sesión mediante Google Sign-In.
  • Conectar pasajeros con conductores.
  • Calcular rutas, tiempos, distancias y tarifas estimadas.
  • Mostrar ubicación del conductor y del viaje cuando corresponda.
  • Procesar solicitudes, cancelaciones, viajes e historial.
  • Verificar conductores, vehículos y documentos.
  • Gestionar recargas, wallet, comisiones y comprobantes.
  • Enviar notificaciones operativas sobre viajes, cuenta, seguridad y soporte.
  • Atender reportes, reclamos e incidentes.
  • Prevenir fraude, abuso, suplantación, uso indebido y riesgos de seguridad.
  • Cumplir obligaciones legales, regulatorias o solicitudes válidas de autoridades competentes.
  • Mejorar la estabilidad, seguridad y funcionamiento de la aplicación.

4. Servicios de terceros

Bless Rides puede utilizar servicios de terceros para operar correctamente. Estos proveedores pueden procesar datos de acuerdo con sus propias políticas y contratos aplicables.

  • Google Sign-In / Firebase Authentication: para autenticación de usuarios.
  • Firebase Firestore: para almacenar datos operativos de cuenta, viajes, estados, solicitudes y configuración.
  • Firebase Storage: para almacenar imágenes, fotos, documentos y evidencias subidas por usuarios.
  • Firebase Cloud Functions: para procesos backend, validaciones y operaciones seguras.
  • Firebase Cloud Messaging: para notificaciones push.
  • Google Maps, Places, Directions y Geocoding: para mapas, rutas, búsqueda de lugares, cálculo de distancia y ubicación.
  • Yappy u otros proveedores de pago: para recargas, comprobantes o procesos relacionados con wallet, cuando estén disponibles.

5. Información compartida entre usuarios

Para que el servicio funcione, cierta información puede mostrarse entre pasajero y conductor.

  • El pasajero puede ver datos del conductor, vehículo, ubicación durante el viaje y datos necesarios para seguridad.
  • El conductor puede ver datos necesarios del pasajero, punto de recogida, destino, referencia del viaje y, cuando aplique, información de verificación visual.
  • El chat del viaje puede estar disponible durante un viaje activo.

6. Permisos del dispositivo

Bless Rides puede solicitar permisos como:

  • Ubicación: necesaria para mapas, viajes, recogida, destino y modo conductor.
  • Cámara: para foto de perfil, selfies, verificación visual, documentos o evidencias.
  • Archivos o galería: cuando el usuario sube documentos, imágenes o comprobantes permitidos.
  • Notificaciones: para avisos operativos relacionados con viajes, cuenta, soporte o seguridad.

7. Conservación de datos

Conservamos los datos mientras la cuenta esté activa o mientras sean necesarios para prestar el servicio, cumplir obligaciones legales, resolver disputas, prevenir fraude, mantener seguridad o cumplir requisitos contables, fiscales o regulatorios.

Algunas evidencias temporales, como verificaciones visuales, pueden conservarse por periodos limitados cuando sea necesario para seguridad, soporte o investigación de incidentes.

8. Eliminación de cuenta y datos

Los usuarios pueden solicitar la eliminación de su cuenta desde la aplicación en la sección de perfil, usando la opción de eliminación de cuenta cuando esté disponible.

También pueden solicitar la eliminación de cuenta o datos desde la página de Eliminación de cuenta y datos.

Algunas informaciones pueden conservarse cuando sea necesario por obligaciones legales, prevención de fraude, seguridad, disputas, registros financieros o cumplimiento regulatorio.

¿Necesitas ayuda?Para consultas sobre privacidad o eliminación de información, escribe a blessridesapp@gmail.com.

9. Seguridad

Aplicamos medidas razonables para proteger los datos, incluyendo controles de acceso, autenticación, almacenamiento seguro, reglas de acceso, cifrado en tránsito y monitoreo operativo. Sin embargo, ningún sistema es completamente seguro.

10. Derechos del usuario

Los usuarios pueden solicitar acceso, corrección, actualización, eliminación u oposición al tratamiento de sus datos, cuando corresponda conforme a la ley aplicable.

Para ejercer estos derechos, pueden escribir a panaisolutions@gmail.com.

11. Menores de edad

Bless Rides no está dirigida a menores de edad. Si detectamos una cuenta creada por un menor sin autorización válida, podremos suspenderla o eliminarla.

12. Cambios a esta política

Podemos actualizar esta Política de Privacidad para reflejar cambios legales, técnicos u operativos. La versión vigente estará disponible en esta página con su fecha de última actualización.
